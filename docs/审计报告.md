# SuperSampler 文档审计报告

> 2026-09-18。审计并修复已发布文档，按用户标准：**详细、准确、简单易读，内部实现不过度描述，第一版不说旧版本的事**。
> 审计基准：源码（`src/` 契约、引擎、配置加载器）；覆盖基准：用户使用框架必须知道的知识面。

## 1. 范围与方法

- **被审文档（5 份）**：`README.md`、`docs/使用说明.md`、`docs/配置XML说明.md`、`docs/框架API说明.md`、`samples/InjectionLineMonitor/README.md`。
- **方法**：三个只读审计代理按文档分派，逐条对照源码核实（配置默认值/枚举、门面 API 签名、事件字段、行为语义、打包命令），产出五类发现：**准确性 / 覆盖缺口 / 内部实现痕迹 / 旧版本叙事 / 可读性**；随后三个修复代理按文件并行修复；主代理验收抽查。
- **共 68 条发现**，其中**准确性硬错误 10 处（高）**，已全部按源码定论修正。
