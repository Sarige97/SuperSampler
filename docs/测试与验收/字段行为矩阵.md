# 配置字段「解析生效 + 行为生效」逐字段矩阵（schemaVersion 3.0）

> 本轮目标（用户原话）：**每一个支持的配置（每一个字段属性）是否正常生效**。
> 权威字段清单：`Config/配置字段说明.md`（§1–§15 字段表）+ 样例 `Config/上位机配置.v3.xml`，
> 并与加载器代码逐节核对（`src/SuperSampler.Core/Config/SamplerConfigLoader*.cs`、`SamplerConfiguration.cs`）。
> 上一版矩阵（P2 期口径）见 `_testplan/field-coverage.md`；缺陷记账见 `_testplan/findings.md`。

---

## 1. 生效判据（本轮口径）

一个字段只有同时满足两件事才算「生效」：

| 维度 | 判据 | 证据形式 |
|---|---|---|
| **解析生效** | 写进 XML 后被加载器读进运行时模型：值正确、缺省正确、非法值报错 | `FieldCoverageTests.Parses_field` / `Applies_default` / `Inherits_field` 行，或专用 Fact，或非法值用例 |
| **行为生效** | 真的影响运行，不是「解析了但没人用」 | 见下方三条消费者路径 |

**行为生效的三条消费者路径**（命中任一即算生效，矩阵「行为生效」列给出路径与用例）：

- **(A) 框架运行路径**：调度 / 编解码 / 写管道 / 退避 / 报警 / 事件 —— 有断言「改变字段 → 改变可观测结果」的用例
  （请求次数与地址、解码值、质量、事件、下发帧、校验拒绝）。
- **(B) 宿主接口**：经 `RuntimePoint` / `PointConfig` / `SamplerConfiguration` / 门面
  (`IDeviceManager` / `IModbusDebugTool`) 公开给宿主，且**样例宿主 `samples/InjectionLineMonitor` 实际消费**。
- **(C) 加载期校验**：非法值被加载期规则拒绝（CGV-*），即「不生效就报错」。

> **(B) 的口径说明（重要）**：有一类字段的语义**就是「说明文字/计量单位」**，不可能有任何框架行为——
> `Meta/*`（工程名、备注、作者、日期、修订、标签）、`Point@desc/@unit/@readonlyBy`、`Device@name/@desc`。
> 它们的契约是「框架解析进模型 + 宿主取用」，判 **生效(B)**（本轮补可达性用例，且解析已由 `Parses_field` 行覆盖）。
> 与之相对，**语义是要改变行为或数值、却没有任何消费者**的字段（如 `Global@timeZone`、`Global/Retry@backoff`、
> `Write@step`、`Point@range`）一律判「仅解析」并按 ADR D30 显式告警——因为静默忽略它们会产出**错误的值或错的行为**，
> 而忽略一段说明文字不会。这条界线是 §3 处置清单的唯一判据。

## 2. 结论取值

| 结论 | 含义 |
|---|---|
| **生效** | 解析生效 + 行为生效（路径 A/B/C） |
| **仅解析→已告警** | 加载器读进模型，但无任何消费者；本轮按 ADR D30 的「显式告警」分支处置：写了即进 `Warnings` |
| **仅解析→已接线** | 原为仅解析，本轮接线到运行路径（补行为用例） |
| **已删除（零兼容）** | 字段已删；写了**直接报错**，不做兼容解析（CGV-25/26/29） |
| **未实现段** | 整段按 `unsupportedPolicy` 告警（Drivers/Storage/Ui/Users/Commands/Trace/Events/Recovery/History/Tags/Parsers/Simulate/generateDiagnostics/AlarmClass 展示属性/Scale@mode） |

## 3. 本轮 D30 处置决定（「解析了但行为没生效」清单）

判据：字段语义是**要改变行为/数值**的，却没有任何消费者 → 必须处置（接线 / 删除 / 显式告警）。
纯说明文字类的宿主元数据不在此列（见 §1 的口径说明）。

| # | 字段 | 原状态 | 处置 | 理由与落点 |
|---|---|---|---|---|
| 1 | `Global/Retry@backoff` | 解析进 `GlobalOptions.RetryBackoff`，无消费者 | **显式告警** | 重试间隔策略未实现（间隔恒为 `intervalMs`）；退避语义已由两层 `Global/Reconnect@delays` 承担 |
| 2 | `Global/Retry@escalateAfter` | 解析，无消费者 | **显式告警** | 「连续 N 次超时升级链路故障」未实现；升级由 `BackoffGovernor`「同链路全部从站设备级退避 → 升级链路级」承担 |
| 3 | `Global/Retry@budgetMs` | 解析，无消费者 | **显式告警** | 驱动重试循环只按 `Retry@count` 计次，不做时间预算 |
| 4 | `Global/Retry@maxBackoffMs` / `@onLinkError` / `@onException` | **根本没解析** | **显式告警** | 写了完全被忽略；语义分别由 `Reconnect@delays` 队列、链路错不重试、异常码 05/06/0A 瞬时重试承担 |
| 5 | `Global@timeZone` | 解析，无消费者 | **显式告警** | 框架无显示层（日期时间按机器本地时区解）；静默忽略会让宿主以为时区已生效 |
| 6 | `Point@range` | 解析进 `RangeLow/RangeHigh`，无消费者 | **显式告警** | 契约是「界面刻度 / 百分比死区」，两者都没实现（`History@deadbandMode=percent` 属未实现段） |
| 7 | `Write@confirm` | 解析，无消费者 | **显式告警** | 二次确认是宿主界面动作，写管道不消费 |
| 8 | `Write@step` | 解析，无消费者 | **显式告警** | 步进是界面语义；写管道只做 min/max 范围校验，不做步进网格校验 |
| 9 | `Write@permission` | 解析，无消费者 | **显式告警** | 角色体系（顶层 `Users`）未实现，无角色可校验；写管道按放行处理 |
| 10 | `Transport@driver` / `@maxConcurrent` | 已删除的属性，写了静默忽略 | **显式告警** | 字典 §18 标为已删除；不静默（改判告警而非报错：旧配置仍可加载，但用户看得见） |
| 11 | `Transport/Reconnect` | 整段未解析 | **显式告警** | 退避参数只走 `Global/Reconnect` |
| 12 | `bcd` 点位的值处理管道 | 解码漏 `Scale`、编码写**二进制**（不是 BCD） | **接线（缺陷 D42）** | 读写路径都不对称，写 BCD 点位会往线上写非法表示 |
| 13 | `Format@decimals` 对整型/BCD 工程值 | 整型走 `IFormattable` 分支，`decimals` 被忽略 | **接线（缺陷 D43）** | 样例配置 `dataType="bcd"` + `decimals="2"` 显示不出小数 |
| 14 | `Transport@enabled=false` | 解析，无消费者（禁用链路照常轮询） | **接线（缺陷 D44）** | 链路停用应是整条链路一起停：不建主站、不轮询、手动重试返回 NotSupported |
| 15 | `Device@desc` | **根本没解析**（写了被忽略） | **接线** | 解析进 `DeviceConfig.Desc`，与 `Point@desc` 同口径的宿主元数据 |

> 处置只选一条，绝不留「静默」：能接线就接线（12–15），无框架语义的走显式告警（1–11）。
> 告警只对**显式写了**的属性生效——不写不告警（缺省值不产生噪声），并受 `HostConfig@unsupportedPolicy` 统一控制
> （`error` 时升级为拒绝加载）。

## 7. 未覆盖 / 存疑（如实登记）

| 项 | 原因 |
|---|---|
