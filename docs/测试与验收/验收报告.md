## 4. 能力分层（可直接用 / 有条件可用 / 必须宿主自己补）

### 4.1 可直接用（真链路验证过）
- 配置：加载 + 校验 + `unsupportedPolicy` 三策略 + i18n（按 `@lang` 选文件）+ 模板继承 + PLC 编址 + 点位级 `unitId`（网关多从站）
  + 词汇白名单校验（未知元素报错）
- 采集：四区全类型（含 int64/uint64/float64/BCD/datetime/raw/位域/枚举/位映射展开/Slices）、
  块读与散点自动分组（上限/容差配置驱动）、点位/块 `mode`=auto/once/onDemand、停用点/块、四字序
- 写：范围拒绝（零通讯）、只读区拒绝、verify 回读 + `VerifyMismatch`、脉冲点动、位读改写、写四态、
  **写路径恒 0 重试（超时绝不自动重写）**、**门面报警确认 API**、BCD/datetime/raw 可写
- 报警：越限→延时→触发→确认→回差清除→锁存不重触发，坏值期间挂起
- 事件/错误：6 类订阅、`IErrorEvent` 基接口订阅、**聚合单位 = 读取窗口**、丢弃计数可见、写审计四字段
- 韧性：refuse(RST) / silent / 丢包 / 延迟 / 半开 注入下**不崩不卡**，恢复后质量回 Good；
  两级退避（设备级/链路级）+ keepalive + 手动重试 + `BackoffEntered/RecoveredEvent`；质量策略 bad/offline/uncertain/keepLast 均生效
- 计算与脚本：表达式（P/T、类型统一 double）、脚本解码（ES5.1，超时保护）、计算点递归求值与防环

### 4.2 有条件可用（需按语义使用）
- 多字点位字序：块未显式声明 swap 时不传染（链 `Point > Block(显式) > Defaults > Device > Global`）
- `unixms` 时间戳需 **4 字**；`bcd(N)`/`datetime(格式)` 字长按类型自动推导，不要手写 `length`
- 链路错 vs 超时：RST/断电/0x0B → `LinkDown`（走链路级退避）；慢响应才是超时（设备级退避）
- i18n：多语言按 `Global@language` 选文件；脚本路径与门面路径的取值口径已统一
- `variant="udp"/"ascii"` **别用**（会被静默按 TCP 处理，W79）

### 4.3 必须宿主自己补（框架不提供，见 findings「宿主级缺口」）
| 缺口 | 现场后果 | 现状 |
|---|---|---|
| 设备/链路在线状态 | 只能靠逐点质量推断（实测停桩后滞后 ~14s 才变 Bad） | 未提供一等公民 API |
| 报警查询（激活清单 / 待确认） | 只能盲确认，做不出"报警总览"画面 | 未提供 |
| 计算点不发值事件 | 计算点只能轮询 `GetValueDetail`，无法订阅 | 未提供 |
| 点位元数据门面 | 做点位树/画面必须直接引用内部类型 `Core.Runtime.PointRegistry` | 边界冲突 |
| 任意 `PointValue` 格式化 API | 想把写回值按点位格式显示，只能 `GetValue`（读到轮询缓存旧值） | 未提供 |
| `pulseMs` 同步 `Thread.Sleep` | 点动期间其它写排队（实测 804ms），自动写回无审计 | 设计待改 |
| `staleAfterMs` | 只解析不消费，宿主需用 `GetValueAge` 自判 | 已知限制 |
| 权限/命令引擎/历史存储/界面/配方/报表/对时/多客户端/报警升级 | —— | 全归上位机，见 `docs/10` |

> **已从缺口移出**：写审计事件缺 `Readback`/`VerifyMismatch`（D67 已关闭，现已带 `ElapsedMs/DidReadback/Readback/VerifyMismatch`）；
> BCD/datetime 不可写（D42/D55/D59 已关闭）。
