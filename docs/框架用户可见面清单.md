# SuperSampler 框架用户可见面清单（文档对照基准）

> 2026-09-18。从源码提取的「用户可见面」完整清单，作为文档审计基准与后续维护对照。
> 出处均为 `src/` 源码（契约 / 引擎 / 配置加载器 / 驱动）；本清单只描述**用户（宿主开发者）可见**的事实，不含内部实现。
> 配套：`docs/审计报告.md`（审计过程与修正记录）。

## 1. 配置面

### 1.1 加载入口与异常
- `SamplerConfigLoader.LoadFromXml(string xmlPath)`：从文件加载，**两阶段**（阶段一解析+全量校验收集全部错误；阶段二零错误才产出配置）；任何失败（含读不到文件、非法 XML）统一抛 `ConfigValidationException`。
- `ConfigValidationException`：`Errors`（全部错误行，带定位）+ `Warnings`（同一次加载收集的告警快照）。
- 相对路径（i18n 文件等）以**配置文件所在目录**为基准。

### 1.2 根元素与通用约定
- 根 `<HostConfig schemaVersion="3.0" unsupportedPolicy="warn">`：`schemaVersion` 必填且为 3.x；`unsupportedPolicy` = `warn`（默认）| `error` | `ignore`（未实现段/未消费属性/未知属性的处置）。
- 变量语法：`${KEY}`（i18n 文本）、`P('pointId')`（计算点/脚本取值，只认好值）、`T('key')`（i18n key 取值）。
- 继承链（swap 等）：`Point > Block(显式) > Defaults > Device > Global`。
- 关键枚举：`area` = coil | discrete | input | holding；`dataType` = bool | int16 | uint16 | int32 | uint32 | int64 | uint64 | float32 | float64 | string | bcd | datetime | raw；`swap` = none(ABCD) | byte(BADC) | word(CDAB) | word_byte(DCBA)；`access` = read | write | readwrite。

### 1.3 Global 段（默认值）
- `Global@language`=zh_CN、`@fallbackLanguage`=en_US、`@nullText`="--"、`@swap`=word（CDAB）。
- `Polling@defaultIntervalMs`=1000、`@requestTimeoutMs`=1000（≥1）。
- `Retry@count`=2、`@intervalMs`=100（重试按 count/intervalMs 计次；`backoff/escalateAfter/budgetMs` 无消费者，写了告警）。
- `Reconnect@enabled`=true、`@delays`="300,1000,3000,10000,30000"（毫秒显式队列，逐档等待、用尽循环末值、项数≤32）、`@manualRetry`=true、`@offlineQuality`=offline（|bad）。
- `Scheduler@groupLimitRegisters`=125、`@groupLimitBits`=2000、`@ignoreGap`=0。
- `Script@timeoutMs`=50、`@onError`=markBad。
- `Quality@onCommError`=bad（|offline|uncertain）、`@onCommErrorValue`=keepLast（|null）、`@staleAfterMs`=5000。
- `Diagnostics@allowRawAccess`=false（原始读写门禁）。

### 1.4 Transport 段
- `variant` = tcp | rtuovertcp | rtu（真实现）；**udp / ascii 未实现**（写了告警，按 TCP/MBAP 收发）。
- `port` 默认 502；`connectTimeoutMs`=3000、`requestTimeoutMs`=1000、`gapMs`=0。
- 串口：`portName`、`baudRate`=9600、`dataBits`=8、`parity`=none（|even|odd|mark|space）、`stopBits`=one（|onepointfive|two）、`handshake`=none、`dtr`/`rts`=false、`readTimeoutMs`/`writeTimeoutMs`=500。
- 子元素 `<Retry>`（count/intervalMs）：设备重试覆盖链 `Device/Retry > Transport/Retry > Global/Retry`。

### 1.5 Device 段
- `id`（必填唯一）、`transport`（必填）、`pointSet`（必填）、`unitId` 默认 1（0..255）、`enabled`=true、`swap`（默认继承 Global）、`requestTimeoutMs`=1000。
- 同一 (transport, unitId) 只允许一个启用设备。
- `generateDiagnostics` 未实现（写了告警）。
- 子元素 `<Retry>`、`<Pause maintenance="true">`（检修暂停）。

### 1.6 PointSet / Block / Point（核心）
- `Defaults`：`@area/@dataType/@swap/@unitId/@access`（不承载 intervalMs/mode）。
- `Block`：`id`/`start`/`count`（≥1，≤地址组上限）；`area` 默认 holding、`intervalMs`（≥50）、`mode`、`unitId`、`swap`、`enabled`。块内点位**不得**写 area/unitId/intervalMs/mode；点位地址须落在块窗口内；块内点位地址连续（空洞 ≤ ignoreGap）。
- `Point`：`id`（点表内唯一）、`address`（0 基；`addrFormat="plc"` 时 4xxxx→holding、3xxxx→input、1xxxx→discrete、1..9999→coil）、`dataType` 默认 uint16、`swap`（继承链）、`bit`（0..15）、`bitRange`（"4-7" 含端点）、`intervalMs`（≥50，once 模式不得写）、`mode` = auto | onDemand | once、`access` 默认 read、`unitId`（覆盖）、`enabled`=true。
- 子元素：
  - `<Scale>`：mode 仅 linear（默认；twopoint 等写告警）；`factor`=1.0/`offset`=0.0，或四值 `rawLow/rawHigh/scaledLow/scaledHigh` 双点线性映射（优先）；`<Clamp mode="none|low|high|both" low high>`；写路径逆换算；BCD 点同样吃 Scale。
  - `<Format>`：`decimals`（0..15）、`prefix`/`suffix`、`thousands`、`mapOn`（engineering|raw）、`pattern`（仅 DateTime）、`<Map><Item key value>`（值→文本映射）。
  - `<Write>`：`min`/`max`（min≤max）、`verify`=false（写后回读）、`pulseMs`（点动脉冲）；`step`/`permission`/`confirm` 未消费（写了告警）。
  - `<String>`：`encoding`=ascii、`trimNull`=true、`padding`（0x00..0xFF）、`left`=true。
  - `<Bcd>`：`digits`=4（1..64）。
  - `<DateTime>`：`format` = plc6 | plc4 | unixsec | unixms（字长 6/4/2/4）。
  - `<Script>`：`language`=js（Jint ES5.1）、`timeoutMs`（默认 50，>0）、`onError`=markBad；正文非空；工程值由脚本产出，**不再叠加 Scale**。
  - `<Alarm>`：`id`、`type` = high | highHigh | low | lowLow | digital、`limit`（限值型必填）、`delayMs`（≥0）、`deadband`（≥0）、`priority`（须引用 AlarmClass@id）、`message`、`latch`=false、`ackRequired`=false。
  - `<Bits>`：`<Bit index name text/>` / `<Field from to name text/>` 展开子点位（id = `整字点id.位名`）；只挂单字整数点（bool/int16/uint16）；子点位不挂报警。
  - `<Slices><Slice address length/>`：非连续片段，跨度超地址组上限报错；与 Bits/bit/bitRange 互斥。
  - `<DependsOn><PointRef>`：计算点显式依赖。
  - `<Expression>`：计算点表达式文本。
- 计算点（`PointSet/Calculated/Point`）：必须恰有 Expression 或 Script 之一；不得挂 Bits/Alarm；不占地址。
- 报警限值关系：`lowLow < low < high < highHigh`。

### 1.7 其它段
- `AlarmClasses/AlarmClass@id`（报警 priority 引用目标）；`@name/@color/@sound` 由宿主消费。
- `I18n/Files/File@path/@lang`：`key=value` 行、`#` 注释；选择规则 language → fallbackLanguage → 全部。
- `Meta`：说明性字段。
- **未实现段**（写了按 unsupportedPolicy 告警，默认 warn）：`Storage`、`Commands`、`Ui`、`Users`、`History`、`Trace`、`Device@generateDiagnostics`。

### 1.8 校验规则（用户可见约束，要点）
加载期一次报全：未知元素=错误、未知属性=按 unsupportedPolicy；枚举/数值边界穷举校验（bit 0..15、length≥1、port 1..65535、decimals 0..15、digits 1..64 等）；只读区不得可写、位区不得多字类型；块内点位不得覆盖区/间隔；计算点成环（表达式+脚本+DependsOn）报错；同址同位重复声明报错；报警限值互斥、类型穷举、limit 必填、deadband/delayMs≥0；脚本参数校验；`${KEY}` 必须可解析。

## 2. 门面 API

### 2.1 IDeviceManager（7 方法，寻址主键 (deviceId, pointId)）
- `string GetValue(deviceId, pointId)`：格式化显示串；**质量非 Good 一律返回全局 nullText**；未知 id 抛 `KeyNotFoundException`。
- `PointValue GetValueDetail(deviceId, pointId)`：{值,原始值,质量,时间戳} 四元组（OriginValue=缩放前原始值，计算点/失败/离线为 null）；读缓存不发通讯，可高频。
- `Task<WriteResult> SetValueAsync(deviceId, pointId, object value, CancellationToken)` / `(…, ActingUser user, …)`：完整写管道。
- `Task<AlarmAckResult> AcknowledgeAlarmAsync(deviceId, pointId, alarmId, CancellationToken)` / `(…, user, …)`。
- `TimeSpan? GetValueAge(deviceId, pointId)`：距上次成功采集时长；null=从未成功；框架不做陈旧判定。

### 2.2 IModbusDebugTool（7 方法）
- `RawReadAsync(deviceId, ModbusArea, address, count)` / `RawWriteAsync(...)`：原始寄存器直读直写，不解析；**受 Diagnostics@allowRawAccess 门禁**（默认关，违规抛 InvalidOperationException）。
- `TriggerReadAsync(deviceId, pointId)`：走完整解析管道，写缓存返回。
- `TriggerBlockReadAsync(blockId)`：按块立即读，返回读到的寄存器数。
- `TriggerOnDemandReadAsync(deviceId)`：刷全部 `mode="onDemand"` 项。
- `RetryDeviceAsync(deviceId)` / `RetryLinkAsync(transportId)`：手动重试，**不受门禁**；`manualRetry=false` 或停用链路返回 NotSupported。
- 所有调试请求与轮询共用通道队列，排队不插队。
- `ModbusArea`：Coil / DiscreteInput / InputRegister / HoldingRegister（对应配置 area coil/discrete/input/holding）。

### 2.3 值模型
- `PointQuality`：Good（可信）/ Uncertain（可疑）/ Bad（不可用）/ Offline（离线）。
- `PointValue`：`Value`（bool/int/long/double/string/DateTime/byte[]）、`Quality`、`Timestamp`、`Reason`（非 Good 时的 i18n 原因 key）、`IsGood`、`TryGetValue<T>()`（不抛异常）。
- 常见原因码：`ss.quality.offline`、`ss.reason.shortFrame`、`ss.reason.nan/infinite`、`ss.reason.scriptNull/scriptTimeout/scriptError`、`ss.reason.calculate`。

### 2.4 写入四态
- `Succeeded`：通讯成功（verify=true 时已通过回读）。
- `Failed`：明确失败（设备拒绝/通讯错误/回读确认未生效），可安全重试。
- `Indeterminate`：超时或应答异常，**可能已生效，绝不自动重试**，须回读定论。
- `Rejected`：下发前校验失败（不可写/越界/类型容量/编码失败），**未发出任何通讯**。
- `WriteResult(Outcome, Error, Readback, VerifyMismatch)`；`VerifyMismatch=true` 且 Outcome=Succeeded = 设备钳位，只提示不重试。
- 写请求**恒不重试**（框架保证，与 Retry@count 无关）。
- `ActingUser(Name, RoleId)`：**只用于审计记账**，角色授权当前未实现（`Write@permission` 不生效），授权属宿主职责。

### 2.5 报警确认
- `AlarmAckResult(Outcome)`：`Acknowledged`（已确认，发事件；重复确认幂等）/ `NotPending`（从未触发或不存在，不发事件）。
- 确认键 = `Alarm@id`，未写时 = `pointId#type`。

## 3. 事件面

### 3.1 订阅 API
- `engine.Bus.Subscribe<TEvent>(handler, DeliveryMode=Queued, OverflowPolicy=DropOldest, queueCapacity=null)` / `SubscribeBatch<TEvent>(handler, maxBatchSize, maxBatchDelay, ...)`（传 Inline 一律按 Queued）。
- `DeliveryMode`：Inline（发出方线程同步，无队列）/ Queued（独立有界队列异步送达）。
- `OverflowPolicy`：DropOldest / DropNewest / Wait（阻塞发出方，仅低频不可丢类别）。
- 信封 `IEventEnvelope{Seq, Time, Body}`；订阅 `ISubscription{Delivered, Dropped, Faults, IsActive, Dispose}`；`Metrics`；`HandlerFaulted`（订阅者异常观察点，不影响框架）。
- **先订阅后 Start**（引擎一启动即发事件）。

### 3.2 事件类型（字段即用户可读属性）
- `PointValueChangedEvent`：DeviceId / PointId / Value（只在值或质量相对缓存变化时发）。
- `AlarmRaisedEvent`：AlarmId / DeviceId / PointId / AlarmType / Limit / Value / Priority / Message。
- `AlarmClearedEvent` / `AlarmAcknowledgedEvent`（含 User）。
- `BackoffEnteredEvent`：Scope（Device/Link）/ DeviceId / TransportId / UnitId / Attempt / DelayMs / NextRetryAt / ReasonCode（`MODBUS.TIMEOUT` 设备级 / `MODBUS.LINK` 链路级 / `SS.BACKOFF.ALL_DEVICES` 升级）。
- `BackoffRecoveredEvent`：Scope / DeviceId / TransportId / UnitId / Attempts / DurationMs。
- `PointWrittenEvent`：DeviceId / PointId / Value / User / Outcome / Message / ElapsedMs / **DidReadback / Readback / VerifyMismatch**（所有写操作无论成败都发）。
- 错误族（订阅基接口 `IErrorEvent` 收齐）：`TimeoutError`（可重试）、`LinkError`（需重连）、`ProtocolError`（可重试）、`DeviceExceptionError`（永久，ExceptionCode）、`DecodeError`（永久）、`PolicyError`（策略）、`ConfigError`（永久）、`WriteIndeterminateError`（不确定）。`ErrorInfo`：Code / Category / Level / Source / MessageKey / Context。

## 4. 行为语义（要点）

- **生命周期**：LoadFromXml → new SamplerEngine（未过校验的配置无法实例化）→ 先订阅后 Start → Start → Stop（**Stop 后不可再 Start**，需重建引擎）→ Dispose。
- **调度**：毫秒间隔 ≥50ms（调度节拍）；auto 周期读、onDemand 手动触发、once 启动读一次直到成功；自动分组按 (unitId, area) 合并连续地址，寄存器 ≤125 / 位 ≤2000，超限自动切分。
- **两级退避**：失败一次即进队列；读超时→设备级、IO 失败→链路级、协议异常不计入、同链路全退避→升级链路级、成功一次归零；退避期间不发请求，点位按 offlineQuality 置质量。
- **TCP keepalive**：空闲 10s / 间隔 3s / 探测 3 次。
- **报警**：high/highHigh=值>limit、low/lowLow=值<limit、digital=布尔 true（或非零）；delayMs 延时、deadband 回差（high 回落 limit−deadband 之下才清）、latch+ackRequired 锁存需确认；坏值不参与评估；报警键 = Alarm@id 或 pointId#type。
- **Scale**：工程值 = raw×factor+offset 或双点线性插值，再按 Clamp 钳制；写路径逆换算。
- **脚本**：输入 raw（寄存器数组）/ rawValue（预缩放原始值）/ P('id')（只认好值）/ T('key') / timestamp；返回值即工程值；失败置 Bad + 对应原因码；绝不阻塞采集线程。

## 5. 打包与部署

- 日常构建：`dotnet build SuperSampler.sln`；测试：单测 1257 + 集成 175 = 1432 全绿。
- **单 DLL**：`dotnet build src/SuperSampler.Core/SuperSampler.Core.csproj -c Release -p:EnableILRepack=true` → 产物 `bin/Release/net46/merged/SuperSampler.Core.dll`（Core+Abstractions+Drivers+Jint 四合一，Jint 内嵌，宿主只放这一个文件）。
- 目标框架 net46（4.6~4.8 兼容）；唯一第三方 Jint 2.11.58（已内嵌）；版本 0.1.0；MIT。
- **宿主未验证**：.NET Core/.NET 6 宿主（net46 程序集需 ≥ net461 才可被 .NET Core 引用）。
